## Entry

> Our lawmakers bravely propose regulating artificial intelligence, cryptocurrency, and the entire internet, yet still email their staff a scanned photo of a printed Word document and ask why the PDF won't open.

One satirical sentence (209 characters) roasting lawmakers who would regulate AI, crypto, and the entire internet but cannot convert a file to PDF.

## How it works

`main.ts` deterministically writes exactly the entry line above to `/output/entry.txt` (no trailing newline), with no randomness, no network, and no input. It then re-reads the file and verifies it is exactly the 209-character, one-sentence, one-line entry.

Run with:

```sh
deno run --allow-write=/output --allow-read=/output main.ts
```
